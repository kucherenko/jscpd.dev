- [Types of code clones](/concepts/clone-types): exact, renamed, near-miss and semantic clones, and which of them jscpd finds.
- [How detection works](/concepts/how-detection-works): tokenization per language, normalization and matching.
- [The health score](/concepts/health-score): how duplication, dead code and complexity fold into one 0-100 number.
