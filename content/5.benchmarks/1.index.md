jscpd v5 is benchmarked against five other copy/paste detection tools (jscpd-rs, Duplo, Simian, PMD CPD, and Fallow) across three dimensions:

- **[Detection Speed](/benchmarks/detection-speed)** — jscpd@5 completes in 84ms: the only tool under 100ms, 428× faster than PMD CPD
- **[Multi-Format Detection](/benchmarks/cross-format)** — duplicate detection across Vue, Svelte, Astro, and Markdown blocks
- **[AI Token Efficiency](/benchmarks/ai-token-efficiency)** — the `ai` reporter uses ~79% fewer tokens than the default console output

All benchmarks include full methodology and raw data.
