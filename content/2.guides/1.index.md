## Overview

Reference pages tell you what a flag does. Guides explain when to use it.

| Guide | What it covers |
|-------|----------------|
| [Types of Code Clones](/guides/clone-types) | Exact, renamed, near-miss and semantic clones (Type-1 to Type-4), which of them jscpd finds, and which flag or mode to use for each |
| [Semantic Clones](/guides/semantic-clones) | `--semantic` finds functions that do the same job with different code, within one language or across languages, with a code embedding model: ways to use it, models, embeddings APIs, thresholds and every option (5.3.3+, experimental) |
| [Comparing Two Codebases](/guides/compare) | `--compare` pairs the functions of two folders, in one language or across two, to measure a port or check two implementations of one app for parity: the console, JSON, Markdown and HTML reports with examples, and a live migration map (5.4.0+, experimental) |
| [How Detection Works](/guides/how-detection-works) | How jscpd reads each language by its own syntax before matching: per-format tokenization, the oxc parser for JavaScript and TypeScript, embedded languages, normalization and Rabin-Karp matching |
| [Project Dashboard](/guides/dashboard) | `--dashboard` prints the health badge, project size, duplication by clone kind, the most complex files and dead code on one screen (5.3.0+) |
| [Project Health Score](/guides/health) | `--health` folds duplication, dead code and complexity into one size-aware 0-100 score with a grade, extensible with coverage, test and security metrics (5.3.0+) |
| [Duplication Trend over Git History](/guides/history) | `--history` scans every commit in a range and charts the duplication percentage, with the change between points and how far `--threshold` could be tightened (5.2.1+) |
