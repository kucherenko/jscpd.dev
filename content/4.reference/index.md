The reference describes the current release. It owns the defaults; the guides link here instead of repeating them.

- [CLI options](/reference/cli): every flag of `jscpd`, generated from `jscpd --help`.
- [The config file](/reference/config-file): `.jscpd.json`, the `jscpd` key of `package.json`, where jscpd looks for them, inline markers.
- [Exit codes](/reference/exit-codes): what makes a run exit with 0, 1, 2 or your own code.
- [Reporters](/reference/reporters): the output formats, their file names and options.
- [Supported formats](/reference/supported-formats): the 224 formats, their extensions and shebangs.
- [GitHub Action](/reference/github-action): the inputs and outputs of `kucherenko/jscpd@v5`.
- [Rust crates](/reference/rust-crates): the crates behind the binary.
