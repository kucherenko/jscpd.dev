## Detection Speed

<BenchmarkSpeed />

The chart uses a **logarithmic scale** — each major gridline represents a 10× increase in time. This makes the 428× range between jscpd@5 (84ms) and PMD CPD (35,980ms) visually comparable while preserving differences between the faster tools.

jscpd@5's Rust engine makes it **32× faster** than jscpd@4 (its TypeScript predecessor) and the only tool completing in under 100ms. The next fastest tool, jscpd-rs, takes 33% longer.

## Detection Accuracy

| Tool | Time | Files | Clones | Dup Lines |
|------|------|-------|--------|-----------|
| jscpd@5 | 84ms | 347 | 212 | 9,133 |
| jscpd-rs | 111ms | 360 | 222 | 10,317 |
| Duplo | 162ms | 319 | 518 | 13,049 |
| Fallow dupes | 164ms | 34 | 10 | 3,137 |
| Simian | 964ms | 547 | 424 | 15,351 |
| jscpd@4 | 2.680s | 364 | 211 | 9,969 |
| PMD CPD | 35.980s | 71 | 56 | 2,267 |

Detection accuracy varies significantly:

- **jscpd@5 and jscpd@4** report nearly identical clone counts (212 vs 211), confirming the Rust rewrite preserves detection quality.
- **Duplo and Simian** report the most duplicates but include significant false positives — both are purely text-based without tokenization.
- **PMD CPD** finds the fewest clones (56) despite running for 36 seconds — it only supports 34 languages and cannot process most fixture formats.
- **Fallow dupes** only analyzes TypeScript/JavaScript files (34 of 547), making it unsuitable for polyglot codebases.

## Methodology

- **Target:** `fixtures/` directory — 547 files, 21,645 lines across 150+ language formats
- **Threshold:** Default detection threshold (~5 lines / ~50 tokens) for all tools
- **Timing:** External wall-clock measurement (`date +%s%N`), reported in milliseconds
- **PMD CPD:** Run for all 34 supported languages; results summed
- **Fallow:** Run from inside the target directory (no path argument support)
- **Hardware:** Apple Silicon (Darwin arm64)
- **Last updated:** June 2025

Full methodology details and reproducible commands are in the [jscpd repository](https://github.com/kucherenko/jscpd/blob/master/benchmark/BENCHMARK.md).
