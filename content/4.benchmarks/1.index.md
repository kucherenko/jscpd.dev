jscpd v5 is benchmarked against six other copy/paste detection tools (jscpd v4, jscpd-rs, Duplo, Simian, PMD CPD, and more) across three dimensions:

- **[Detection Speed](/benchmarks/detection-speed)** — jscpd@5 completes in 84ms: 32× faster than v4, 428× faster than PMD CPD
- **[Multi-Format Detection](/benchmarks/cross-format)** — duplicate detection across Vue, Svelte, Astro, and Markdown blocks
- **[AI Token Efficiency](/benchmarks/ai-token-efficiency)** — the `ai` reporter uses ~79% fewer tokens than the default console output

All benchmarks include full methodology and raw data. For the v4 vs v5 comparison on real-world codebases, see the [Migration Guide](/getting-started/migration).
