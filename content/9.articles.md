## Measured on real codebases: duplication numbers before and after

**[How We Turned 636 Code Clones into Solid Architecture](https://woliveiras.com/posts/turning-unknown-duplication-into-solid-architecture/)**
William Oliveira · woliveiras.com, August 2026
> A fantastic tool used by the JavaScript community to preserve code quality is jscpd. Using that tool, we can check if we have code duplication in our projects.

A case study of cleaning up a monorepo (web, mobile, shared packages, APIs, scripts) with a fixed `pnpm dlx jscpd@5` command (5.1.0, --min-lines 10 --min-tokens 70, test globs ignored, console/html/json reporters). The first report mixed in tests and a patch script. After the scope was fixed, the production baseline had 636 clones, 15,887 duplicated lines and 10.95% duplication. The team logged every clone group in a Markdown inventory, used coding agents for the repetitive steps and ended at 168 clones, each one given an owning module or a reason to stay duplicated.

**[Stop Waiting for Better Models](https://amurmann.com/posts/stop-waiting-for-better-models/)**
Alexander Murmann · amurmann.com, April 2026
> The skill runs jscpd across the entire codebase to find duplication clusters.

Personal blog post on building process around Claude Code's weaknesses: a /code-health agent skill (born from BMAD agent retrospectives) runs knip, tsc --noUnusedLocals, jscpd and lizard, and jscpd once flagged auth middleware duplicated across 21 call sites. After the skill was introduced, duplication fell from a peak of 4.7 to 2.9 clones/kLOC, and absolute clones dropped from 116 to 88 while the codebase grew 22%.

**[Déjà Code](https://ngof.nikhaldimann.com/p/deja-code)**
Nik Haldimann · Next Generation Of (Nik Haldimann), February 2026
> Note to some degree I mitigated this issue by excluding trivial duplications in jscpd (those with less than 25 tokens or 5 lines of code).

Case study of GitGuessr, a ~20K-line TypeScript codebase (excluding tests) written entirely by prompting Claude Code over ~500 commits. The author counted duplicated lines with jscpd (--min-tokens 25 --min-lines 5) at every commit and found that deduplicating commits, made at his own prompting, removed 890 lines (~4.5% of the codebase), which he calls a lower bound. As one way the problem could ease, he suggests running jscpd in CI, highlighting new duplicated code and kicking off a cloud agent to propose a refactoring.

**[Fast Fashion for Code](https://www.linkedin.com/pulse/fast-fashion-code-marco-nissen-obtme)**
Marco Nissen · LinkedIn (Code Different newsletter), August 2026
> I looked at one large code base, and ran jscpd against the source tree, with a minimum of eight lines and sixty tokens.

A newsletter essay arguing that AI agents make writing new code cheaper than reusing existing code, which drives duplication up. The author ran jscpd (min 8 lines, 60 tokens) on his own large codebase and found 2,179 exact clones and 46,656 duplicated lines (4.22% of 1,104,572 lines across 2,678 files), which he treats as a floor. He recommends jscpd (with its MCP server, AI reporter and agent skill) as a feedback sensor inside the agent loop and as step one of a scheduled consolidation pass, noting it misses semantically equivalent rewrites.

**[Quality gates for AI-generated code](https://www.linkedin.com/pulse/quality-gates-ai-generated-code-krzysztof-wr%C3%B3bel-jubff)**
Krzysztof Wróbel · LinkedIn Pulse, May 2026
> jscpd scan of the combined source (53 .py files, ~16.6k LOC): 8 clone pairs covering 208 duplicated lines. 208 / 16,600 ≈ 1.25%.

Proposes six CI quality gates for code written by AI agents. The duplication gate is under 3% on new code, and jscpd is the duplication measure. With it the author measures three respected Python libraries at 1.25% (8 clone pairs, 208 lines), and aider's duplication falling from 3.3% to 0.6% over 25 monthly checkpoints as its AI-written share rose. The piece also notes that jscpd has no Zig tokenizer.

**[Your CI Pipeline Wasn’t Built for AI Code. Here’s How to Fix It.](https://medium.com/towards-artificial-intelligence/your-ci-pipeline-wasnt-built-for-ai-code-here-s-how-to-fix-it-70d5cf34993d)**
Christopher Montes · Towards AI (Medium), March 2026
> Start with a tool like jscpd (JavaScript), Simian, or SonarQube's duplication detection configured with lower thresholds than defaults.

A consultant's case study of an AI-powered sales platform, about 130,000 lines of Python and TypeScript across several microservices, where Claude Code and Cursor agents did most new development. It proposes four CI gates. For Gate 1 (duplication and bloat detection) it says to start with jscpd, Simian or SonarQube at lower-than-default thresholds: flag duplications over 20 lines, and don't make it a hard block yet. Its next steps say to run jscpd on your last 20 AI-generated PRs. The team's first scan found over 400 lines of duplicate HTTP client code, and consolidation cut about 15,000 lines of duplicate code to 1,500.

**[HA Widgets — Eigene Home-Assistant-Apps mit Vue 3 (Teil 4: Architektur-Checks und Duplikate)](https://blog.stephanys.de/2026/04/ha-widgets-eigene-home-assistant-apps-mit-vue-3-teil-4-architektur-checks-und-duplikate)**

Part 4 of a series on three Vue 3 Home Assistant apps (desktop, phone, tablet) that share a common library. **[Medí antes de tocar: cómo pasé un Quality Gate de SonarQube](https://chocopy.medium.com/med%C3%AD-antes-de-tocar-c%C3%B3mo-pas%C3%A9-un-quality-gate-de-sonarqube-978928df8b78)**
Cbenitez (Cristhian Benitez) · Medium (chocopy.medium.com), July 2026
> jscpd con --min-tokens 50 agarra clones chiquitos que Sonar ni cuenta — Sonar recién marca duplicación arriba de ~100 tokens.

A first-person case study of getting a failing SonarQube Quality Gate to pass (68 violations, 3.55% duplication, 55% coverage). The author ran jscpd to find duplicate blocks, but the ~45-token spinner and 'not found' blocks he extracted didn't count in Sonar, which only counts clones above ~100 tokens. Moving one fetch block copied across 8 screens into hooks dropped Sonar's duplication from 3.55% to ~2.35%; the lesson is to measure against the gate's own metric, not jscpd's.

A long write-up of the Git, Markdown and CI pipeline behind Ben Balter's book 'Open and Async', which builds five formats and runs thousands of automated checks. jscpd is the first of three duplication-detection layers (then an n-gram scan, then an LLM semantic pass) and caught long verbatim blocks pasted between chapters. **[Today I shipped 20 apps and a screensaver](https://blog.gingerbeardman.com/2026/04/17/today-i-shipped-twenty-apps-and-a-screensaver/)**

First-hand account of an indie developer releasing 20 macOS/iOS apps and a screensaver at once. His verdict: the helpers can make the binary slightly bigger, but that is worth it for maintainability.

## Gates, ratchets and SARIF in CI: turning a scan into a build step

**[jscpd で重複コードを機械的に潰す — 定期監査とCI差分チェックの二段構え](https://zenn.dev/singularity/articles/jscpd-dry-detection-mono)**
Isamu (isamua) · Zenn (singularity publication), July 2026
> jscpd はコピペコード検出（Copy/Paste Detector）の定番です。

An in-depth guide to jscpd v5 with a real run of `npx jscpd@5` on the 267k-line MulmoClaude TypeScript monorepo: 512 clones and 3.56% duplication overall (TypeScript 3.27%) in 127 ms. It advises narrowing `format` because markdown and JSON are noise and token % can top 100%, running periodic audits with --blame and the HTML reporter, and not relying on a global --threshold to catch new copies. Instead it uses the official GitHub Action's SARIF output with Code Scanning, compares jscpd with eslint-plugin-sonarjs and SonarQube, and covers the ai reporter, MCP server and dry-refactoring skill.

**[AIでがんがん書く時代の「きれいなコード」の守り方 — ESLint+SonarJS / jscpd / knip をCIに置く](https://zenn.dev/singularity/articles/clean-code-ci-for-ai-era)**
Isamu (isamua) · Zenn (シンギュラリティ・ソサエティ), July 2026
> jscpd はトークン列レベルのコピペ検出器で、v5 系は Rust 製。26万行を0.1秒台で舐めるので、CI に置いてもコストはほぼゼロです。

Walks through the four-tool quality setup (ESLint, SonarJS, jscpd, knip) on the AI-built MulmoClaude monorepo. jscpd runs in a duplication-scan.yaml workflow with --format typescript, ignore globs and console,sarif reporters, and its SARIF goes to GitHub Code Scanning. ## How this page was compiled
